# Nombre del Prompt

Seguimiento estratégico de clientes y oportunidades comerciales

## Objetivo

Realizar un seguimiento profesional de clientes potenciales o actuales para mantener el interés, impulsar el avance de oportunidades comerciales y aumentar las probabilidades de cierre de venta mediante comunicaciones personalizadas y orientadas a resultados.

## Herramienta recomendada

Claude AI

## Área

Ventas

## Cuándo utilizarlo

- Después de una reunión comercial.
- Cuando un cliente no responde a una propuesta enviada.
- Para reactivar oportunidades comerciales inactivas.
- Tras una demostración de producto o servicio.
- Cuando se necesita mantener el contacto sin resultar invasivo.
- Para preparar mensajes de seguimiento adaptados a distintos perfiles de clientes.

## Prompt

Actúa como un consultor experto en ventas B2B y gestión de relaciones con clientes.

Necesito que me ayudes a realizar el seguimiento de un cliente potencial o actual utilizando técnicas de comunicación consultiva y venta relacional.

### Información del cliente

- Empresa: [Nombre de la empresa]
- Sector: [Sector]
- Contacto principal: [Nombre y cargo]
- Producto o servicio ofrecido: [Descripción]
- Fecha de la última interacción: [Fecha]
- Resumen de la conversación anterior: [Detalles]
- Estado actual de la oportunidad: [Prospección, negociación, propuesta enviada, pendiente de respuesta, etc.]
- Objetivo del seguimiento: [Concertar reunión, resolver dudas, cerrar venta, obtener respuesta, etc.]

### Tareas a realizar

Genera:

1. Un análisis breve de la situación comercial.
2. Los puntos clave que debería abordar en el seguimiento.
3. Un correo electrónico profesional y personalizado.
4. Una versión corta para LinkedIn o WhatsApp.
5. Posibles objeciones que podrían surgir y cómo responderlas.
6. Próxima acción recomendada para avanzar la oportunidad.
7. Consejos para aumentar las probabilidades de respuesta del cliente.

Utiliza un tono profesional, cercano y orientado a generar confianza y valor para el cliente.

## Resultado esperado

Al ejecutar este prompt se obtendrá:

- Un diagnóstico rápido de la oportunidad comercial.
- Correos de seguimiento personalizados y adaptados al contexto.
- Mensajes breves para distintos canales de comunicación.
- Estrategias para superar objeciones habituales.
- Recomendaciones concretas para avanzar el proceso de venta.
- Próximos pasos claramente definidos para el equipo comercial.

## Recomendaciones

- Proporciona siempre el máximo contexto posible sobre las conversaciones previas.
- Define claramente el objetivo de la comunicación.
- Incluye necesidades, retos o intereses detectados durante la negociación.
- Actualiza la información tras cada interacción para mantener un seguimiento continuo.
- Solicita diferentes enfoques (consultivo, directo, educativo o basado en valor) para comparar alternativas.

## Variantes

### Seguimiento tras envío de propuesta

**Prompt:**

Genera una estrategia de seguimiento para un cliente que recibió una propuesta comercial hace 7 días y todavía no ha respondido. Incluye un correo electrónico, mensaje de LinkedIn y argumentos para recuperar la conversación sin generar presión.

### Reactivación de cliente inactivo

**Prompt:**

Analiza cómo reactivar un cliente que no interactúa con la empresa desde hace más de seis meses. Propón un plan de contacto, mensajes personalizados y oportunidades de valor para recuperar el interés.

### Seguimiento después de una reunión comercial

**Prompt:**

Redacta un correo de seguimiento tras una reunión comercial, resumiendo los acuerdos alcanzados, próximos pasos y beneficios de la solución presentada.

### Seguimiento para cierre de venta

**Prompt:**

Actúa como un director comercial senior. Analiza la oportunidad y genera una estrategia de seguimiento enfocada en acelerar la toma de decisión y el cierre de la venta sin resultar agresivo.
