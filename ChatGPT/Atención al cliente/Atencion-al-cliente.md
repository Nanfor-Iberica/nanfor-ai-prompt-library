# Nombre del Prompt

Asistente Inteligente para Gestión de Incidencias y Atención al Cliente

## Objetivo

Ayudar a los equipos de Atención al Cliente a analizar consultas, reclamaciones e incidencias de forma rápida y profesional, generando respuestas claras, empáticas y orientadas a la resolución del problema.

## Herramienta recomendada

ChatGPT

## Área

Atención al Cliente

## Cuándo utilizarlo

- Gestión de incidencias y reclamaciones.
- Respuesta a consultas de clientes por correo electrónico o chat.
- Atención postventa.
- Seguimiento de solicitudes pendientes.
- Gestión de clientes insatisfechos.
- Elaboración de respuestas estandarizadas manteniendo un tono personalizado.
- Reducción de tiempos de respuesta del equipo de soporte.

## Prompt

Actúa como especialista senior en Atención al Cliente y Experiencia del Cliente (Customer Experience).

Analiza la siguiente consulta o incidencia recibida por un cliente y genera una respuesta profesional orientada a la resolución del problema.

**Información de la consulta:**

[PEGAR MENSAJE DEL CLIENTE]

**Contexto de la empresa:**

- Sector: [INDICAR SECTOR]
- Producto o servicio: [DESCRIBIR]
- Política de atención: Priorizar la satisfacción del cliente, ofrecer soluciones claras y mantener una comunicación profesional y empática.

**Tu tarea es:**

1. Identificar el problema principal planteado por el cliente.
2. Detectar posibles emociones reflejadas en el mensaje (frustración, duda, urgencia, confusión, etc.).
3. Elaborar una respuesta profesional y empática.
4. Proponer una solución concreta o los siguientes pasos.
5. Indicar si es necesario escalar el caso a otro departamento.
6. Finalizar con una llamada a la acción clara para el cliente.

**Formato de salida:**

### Resumen del caso

### Nivel de prioridad

- Baja
- Media
- Alta

### Emoción detectada

### Respuesta sugerida al cliente

### Recomendación interna para el equipo

### Próximos pasos

Utiliza lenguaje profesional, cercano y orientado a la resolución efectiva de problemas.

## Resultado esperado

El usuario obtiene:

- Un análisis rápido de la situación.
- Una respuesta lista para enviar al cliente.
- Identificación de riesgos de satisfacción.
- Recomendaciones de actuación para el equipo.
- Mayor consistencia en las comunicaciones.
- Reducción de tiempos de gestión.

**Ejemplo:**

**Cliente:**

> "He intentado acceder a la plataforma durante toda la mañana y sigue apareciendo un error. Necesito realizar una gestión urgente y nadie me responde."

**Resultado esperado:**

- Detección de incidencia técnica.
- Identificación de urgencia alta.
- Respuesta empática.
- Propuesta inmediata de solución.
- Recomendación de derivación al equipo técnico.

## Recomendaciones

- Facilitar siempre el mensaje completo del cliente para obtener un análisis más preciso.
- Incluir información del producto, servicio o contrato cuando sea relevante.
- Utilizar este prompt como primer filtro antes de responder manualmente.
- Revisar los datos sensibles antes de enviar la respuesta final.
- Adaptar el tono al tipo de cliente (particular, empresa, partner o proveedor).
- Combinar este prompt con sistemas CRM para mejorar el seguimiento de incidencias.

## Variantes

### Variante 1: Atención por correo electrónico

Especializada en generar respuestas formales para clientes empresariales mediante email.

### Variante 2: Atención por chat en tiempo real

Optimizada para respuestas breves, rápidas y orientadas a la conversación.

### Variante 3: Gestión de reclamaciones

Enfocada en clientes insatisfechos, incidencias críticas y recuperación de confianza.

### Variante 4: Seguimiento postventa

Orientada a verificar la satisfacción del cliente después de resolver una incidencia o implementar una solución.

### Variante 5: Atención B2B

Diseñada para clientes corporativos que requieren respuestas más técnicas, ejecutivas y alineadas con acuerdos de nivel de servicio (SLA).
