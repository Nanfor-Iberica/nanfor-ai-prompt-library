# Nombre del Prompt

Análisis Financiero Avanzado de Datos en Excel con Microsoft Copilot

## Objetivo

Analizar información financiera contenida en hojas de cálculo de Excel para identificar tendencias, detectar desviaciones presupuestarias, calcular indicadores clave y generar conclusiones accionables que faciliten la toma de decisiones empresariales.

## Herramienta recomendada

Microsoft Copilot

## Área

Finanzas

## Cuándo utilizarlo

Utiliza este prompt cuando necesites:

- Analizar presupuestos y gastos empresariales.
- Comparar resultados financieros entre diferentes periodos.
- Detectar desviaciones respecto a objetivos financieros.
- Evaluar ingresos, costes y márgenes de beneficio.
- Identificar tendencias financieras en grandes volúmenes de datos.
- Preparar informes financieros ejecutivos.
- Obtener conclusiones rápidas sin realizar análisis manuales complejos.

## Prompt

Actúa como un analista financiero senior especializado en inteligencia empresarial.

Analiza los datos contenidos en este archivo Excel y genera un informe financiero detallado orientado a la toma de decisiones.

Realiza las siguientes tareas:

1. Resume el contenido general de los datos.
2. Identifica los principales indicadores financieros disponibles.
3. Calcula y destaca tendencias relevantes en ingresos, gastos, beneficios y márgenes.
4. Detecta desviaciones significativas respecto a periodos anteriores o presupuestos definidos.
5. Identifica posibles oportunidades de ahorro o mejora de rentabilidad.
6. Señala riesgos financieros o comportamientos inusuales presentes en los datos.
7. Genera una tabla resumen con los hallazgos más importantes.
8. Presenta conclusiones ejecutivas y recomendaciones prácticas para la dirección financiera.

Contexto empresarial:

- Sector: [INDICAR SECTOR]
- Periodo analizado: [INDICAR PERIODO]
- Objetivo del análisis: [INDICAR OBJETIVO]

El resultado debe ser claro, profesional, orientado a negocio y apto para presentar ante responsables financieros o dirección general.

## Resultado esperado

Un informe financiero estructurado que incluya:

- Resumen ejecutivo.
- Principales KPIs identificados.
- Evolución de ingresos, costes y beneficios.
- Desviaciones destacadas.
- Riesgos detectados.
- Oportunidades de optimización financiera.
- Recomendaciones accionables.
- Conclusiones estratégicas para la toma de decisiones.

Ejemplo de resultado:

- Ingresos aumentaron un 12% respecto al trimestre anterior.
- Gastos operativos crecieron un 18%, superando el crecimiento de ingresos.
- El margen neto se redujo un 4%.
- Se detecta una concentración excesiva de costes en proveedores específicos.
- Existe una oportunidad de ahorro estimada en determinadas partidas de gasto recurrente.
- Se recomienda revisar contratos y optimizar procesos con menor rentabilidad.

## Recomendaciones

- Mantener una estructura homogénea en las hojas de cálculo.
- Utilizar nombres claros para columnas y categorías financieras.
- Incluir periodos comparativos para obtener análisis más precisos.
- Incorporar presupuestos y objetivos financieros cuando estén disponibles.
- Validar posibles valores atípicos antes de tomar decisiones estratégicas.
- Complementar el análisis con indicadores propios del sector.

## Variantes

### Variante 1: Análisis de presupuesto

Analiza este Excel comparando presupuesto versus gasto real. Identifica desviaciones, calcula porcentajes de cumplimiento y propone acciones correctivas prioritarias.

### Variante 2: Análisis de rentabilidad

Analiza la rentabilidad por producto, servicio, cliente o unidad de negocio. Identifica cuáles generan mayor beneficio y cuáles están reduciendo el margen global.

### Variante 3: Control de gastos

Examina todas las partidas de gasto, detecta incrementos inusuales y propone oportunidades de optimización para reducir costes sin afectar la operativa.

### Variante 4: Proyección financiera

Utiliza los datos históricos disponibles para estimar tendencias futuras de ingresos, gastos y resultados financieros. Incluye escenarios optimista, conservador y pesimista.
